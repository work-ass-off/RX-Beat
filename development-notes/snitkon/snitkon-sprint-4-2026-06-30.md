# Sprint 4: HTTP, RxJS & Testing — 2025-06-30

- **What was done:** Designed and implemented a scalable architecture for media data fetching by introducing JamendoAbstractService, an abstract base class that encapsulates reusable HTTP workflows and reactive state management for Tracks, Albums, and Artists features. Utilized this abstract class as an Injection Token within the Angular Router configuration (providers), enabling dynamic service substitution (useClass) to supply feature-specific implementations (JamendoTracksService, JamendoAlbumsService) directly to contextual route boundaries. Developed a centralized RoutingService leveraging Router.events and the root routerState.snapshot to reactively extract path metadata and dynamic parameters (:id) without component-level ActivatedRoute coupling. Refactored the core user interface using modern Angular template control flow (@if, @else, @for, and @let declarations) with an async pipe strategy, and secured the view boundaries with integrated AuthService state validation.
- **Problems:**
    * Required a highly reusable abstraction layer for API requests to avoid duplicating search and ID-based fetching logic across different media types, while preserving unique configurations (e.g., popularity sorting, limits).
    * Encountered issues with Angular's hierarchical Dependency Injection where child routes on the same injection level shared a parent instance, resulting in state cross-contamination and an infinite Change Detection loop (NG0103) when mutating streams during data loading.
    * Encountered an asynchronous race condition where an HTTP interceptor toggle for a HttpContext-driven loading signal caused the immediate destruction of a template @else block, triggering an early RxJS unsubscription, request cancellation, and subsequent rendering loop.
    * Needed an accessible, SEO-compliant navigation mechanism for unauthorized user interaction state boundaries that aligns with structural HTML best practices.
- **Solutions:**
    * Engineered JamendoAbstractService<T> using TypeScript generics, exposing a unified data$ stream tied to a reactive search state, and extended it into lightweight feature services containing custom API endpoints and parameters.
    * Isolated route scopes by declaring independent JamendoAbstractService tokens via useClass on child route parameters, providing clean, separate instances for components rendered simultaneously within nested <router-outlet> blocks.
    * Restructured the control flow template by decoupling the @let tracks = tracks$ | async stream instantiation from the conditional @if (loading()) layout branches, ensuring the RxJS stream subscription remains stable and uninterrupted through the entire HTTP interceptor lifecycle.
    * Replaced basic action components with semantic anchor tags (<a>) configured with routerLink for page-to-page authorization redirects, guaranteeing native browser behaviors like right-click menu options and Ctrl/Cmd new-tab target support.
- **What I learned:**
    * Deepened my mastery of Angular’s Dependency Injection system, specifically how EnvironmentInjectors are instantiated at the route level, and how to utilize abstract classes as unified tokens for polymorphically swapped services.
    * Developed a comprehensive understanding of the new Angular @let syntax lifecycle, learning that its underlying async pipe subscription is lazily bound to its first evaluation in the active DOM branch.
    * Discovered how synchronized state mutations (like immediate signal changes inside HTTP interceptors) can trigger destructive layout re-evaluation and learned architectures to keep presentation states separate from data streams.
    * Gained practical experience in abstracting routing details into isolated singleton services, reducing component logic density and improving overall testability.
- **Plans:** Focus on data persistence layers, implementing client-side request caching for heavy media responses, creating automated token-refresh mechanisms within functional HTTP interceptors, and integrating audio playback state management using Web Audio APIs.
